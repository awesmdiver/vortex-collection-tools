# Vortex Collection Tools — Vortex Themes

Real color themes for Vortex itself, matching how this tool looks under each of its own game
brands. Install one and Vortex picks up the same accent and background colors you see here.

## Install a theme

1. **Find Vortex's themes folder.** On a standard install, that's `%APPDATA%\Vortex\themes`. If
   you've moved Vortex's data elsewhere, it's wherever **Settings > Theme > Clone** saves a cloned
   theme to instead.
2. **Copy the whole `vct-<name>` folder** (not just the file inside it) into that themes folder.
3. **Restart Vortex, or reopen Settings > Theme.** The new theme shows up in the dropdown, named
   after its folder — for example, `vct-skyrim`.
4. **Pick it from the dropdown.**

Want to fine-tune a color further? Vortex's own **Theme Editor** (the same **Clone** button) works
on these themes just like any other. It edits your own copy in Vortex's themes folder — it never
touches the files here.

## What's included

- `vct-skyrim`
- `vct-fallout4`
- `vct-starfield`
- `vct-plain`

Each is a single `variables.scss` file — that's all Vortex needs to read a theme.
