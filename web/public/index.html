⚠ Before fetching, read this
  1. This only fetches a revision already saved to NexusMods (published or not) -- pick the one you want from the Revision dropdown below.

  3. Recommended: save/upload your latest Workshop changes to NexusMods first, then fetch here.
  4. If you skip that, you'll need to manually reconcile any un-saved changes yourself after rebuilding.

      Update Collection

      Keeps mods you've marked Ignored/Disabled in an installed collection ignored/disabled across a Vortex-driven update. Vortex itself still performs the actual mod installation -- this only brackets that step in Vortex's own state database.

      1

      Backup

      Run BEFORE clicking Update in Vortex.

      Snapshots which mods are currently ignored/disabled for the selected collection.

      Next steps in Vortex
      1. Click Update on this collection.
      2. When prompted, click Download Update.
      3. If a "Remove mods from old revision?" screen appears, choose an option.
      4. On the "collection added" screen, choose Later -- NOT Install Now.
      5. Close Vortex completely, then continue to step 2 below.
      2

      Apply Ignores

      Run AFTER Vortex Update → Later, with Vortex closed.

      Marks the backed-up ignored mods as ignored in the new collection's rules, so Vortex's installer skips them — this is the only step that actually prevents Vortex from installing a mod.

        Next step in Vortex

        Reopen Vortex and click Resume on the collection. This is the slow step (Vortex's own archive extraction) — not controlled by this tool. Once it finishes, close Vortex completely and continue to step 3 below.

        3

        Apply Disables

        Run AFTER Resume finishes, with Vortex closed.

        Restores the disabled state on mods that should stay disabled, now that Vortex has assigned them real mod ids. Uses the profile recorded in the backup itself.

          4

          Compare (optional, anytime)

          Generates an HTML report of what changed vs. the backup, without touching Vortex's state at all.
