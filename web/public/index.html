        ⚠ Before you start
        • Make sure every mod you want to keep is marked Ignored or Disabled in Vortex first -- this tool only preserves whatever is already set, it doesn't set anything for you.
        • If a mod is marked Ignored because you don't want it anymore, make sure it's also removed (deleted) within Vortex. Ignored only stops Vortex from reinstalling it later -- it doesn't remove or disable a mod that's already active.

            Download Missing Archives

            When enabled, Rebuild Collection will automatically download any mod archive it can't find in your downloads folder directly from Nexus before extracting it, instead of skipping that mod.

            Automated downloads only work for Nexus Premium accounts -- Nexus's API refuses this for free accounts by design, the same way Vortex's own client refuses to auto-download for non-Premium users. This respects Nexus's ad-supported download model: free-tier users must download the archive manually from the Nexus website (which shows ads) and let Vortex install it. If your account is not Premium, this tool won't attempt anything else on your behalf -- it will just skip the mod as it does today, with a note in the run log telling you to download and reinstall it yourself via Vortex.

            When enabled, Force Extract will automatically extract any off-site mod archive that you have downloaded, instead of skipping that mod. Note: Vortex might show this a new mod and ask for you to import, make sure you do.

            Performance

            Rebuild Collection extracts mods one at a time by default. Raising this runs several extractions in parallel (each is its own independent process) -- faster for large collections, at the cost of more simultaneous disk/CPU use.

            Backups

            A backup is a full copy of every mod's current staging folder, made just before rebuilding it. For larger collections this option could consume a large amount of disk space.
