Open questions — need your call before I build this
1. Does a custom color replace the theme's own, or sit alongside it?
Proposed default: a personal override layered on top of whichever Style is active — not a new saved "theme" of its own. Pick Skyrim, then customize its purple to whatever you want; switch to Standard, your custom color stays saved for Skyrim and Standard gets its own (or none, if you never touched it there). Simpler than a 3rd concept ("your own custom theme") competing with Style/Font for what "theme" even means. Say the word if you'd rather it work differently.
2. Light/dark Appearance mode — one color for both, or two?
Proposed default: one color for both modes, same as Skyrim's own purple today (Plain is the one exception, with real separate light/dark hex values baked in from before theming existed at all). Asking for two picks (one per Appearance mode) is more correct but doubles the UI for a case most people won't need. Flag if you want the fuller two-color version instead.
3. Where does "Reset" reset TO?
Proposed: back to whatever the currently-selected Style's own default is (Skyrim's purple, Standard's blue) — not to some third neutral default. Shown above as "Reset to Skyrim's own purple," which would read "Reset to Standard's own blue" if Style were set to Standard instead.
