🧬 Merge Many Plugins Into One

Skyrim's plugin slots fill up fast. Pick plugins from one or more collections and this tool bundles them into a single file—freeing up slots without touching xEdit. Review exactly what's going in first, and it'll flag the result as .esl automatically when it fits.
